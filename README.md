# Customer Churn & Retention Analytics
Open index.html to view locally. All assets are included.

## Publish with GitHub Pages
1. Create a public GitHub repository called customer-churn-dashboard.
2. Extract this ZIP. In the repository choose Add file → Upload files. Upload index.html, style.css, app.js and the assets folder together to the top level. Commit the files to main.
3. In Settings → Pages select Deploy from a branch, then main and /(root). Save.
4. Once the deployment finishes, choose Visit site in Pages settings.

The charts in the explorer are static exports. Power BI slicer selections are fixed. The website's retention scenario runs locally. To update the project, edit index.html, update the base counts in app.js if needed, and replace the relevant exports in assets.
